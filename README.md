## Избранные проекты

### fitness-program-builder — скилл для Claude
Собирает персональную программу тренировок (мезоцикл 8–12 недель) по анкете клиента и отдаёт готовую HTML-страницу по приватной ссылке. Каждое упражнение — с разбором техники понятным языком, без видео. Рассчитан на широкую аудиторию: от новичков до клиентов 55+ и восстановления после травм.

### posting — контент-завод для соцсетей
Пайплайн автогенерации постов (текст + изображение) для SMB-автоматизации. Несколько AI-шагов работают последовательно: от идеи поста до готового изображения с явной маркировкой, что оно создано ИИ. Уже в бою — несколько постов опубликовано на реальном аккаунте.

**Самое сложное в обоих** — не написать один удачный промпт, а связать несколько AI-шагов в пайплайн, который стабильно работает на разных входных данных и не падает посреди цепочки.
